# Interface Previews & Screenshots

This directory is designated for curated UI screenshots of PixelCraft Launcher.

---

## Privacy Notice on Screenshots

In strict accordance with our [Privacy Policy](../docs/PRIVACY.md), all user-facing screenshots uploaded to this repository undergo rigorous review to ensure:

1. **No Personal Information**: All email addresses, real names, and gamer tags are masked or use test personas (e.g. `Steve`).
2. **No Local File System Exposure**: Local user paths (e.g., `C:\Users\<username>\...`) are scrubbed or sanitized to generic virtual paths.
3. **No Tokens or Secrets**: No OAuth codes, authorization strings, session tokens, or diagnostic dumps containing credentials are ever displayed.

---

## Planned Gallery

Once production screenshots are compiled and redacted, the gallery will showcase:

1. **Play Dashboard**: The main 16-bit retro interface highlighting the active instance, player identity badge, and launch control.
2. **Download Center**: The Modrinth mod, resource pack, and shader exploration interface with loader compatibility tags.
3. **Instance Management Grid**: The multi-instance manager displaying isolated profiles, version badges, and clone/repair menus.
4. **Account & Settings Panel**: The Microsoft OAuth 2.0 account management card and JVM allocation controls.
